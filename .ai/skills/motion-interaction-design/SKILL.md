# Motion / Interaction Design

Motion should communicate:
- causality,
- state change,
- spatial relationship,
- progress,
- feedback.

Avoid:
- motion that delays frequent tasks,
- entrance animation on every element,
- scroll hijacking,
- essential information hidden behind animation,
- ignoring reduced-motion preferences.

Define:
- trigger,
- changing property,
- purpose,
- duration/easing source,
- interruption behavior,
- reduced-motion alternative.

Operational dashboards usually need restrained motion.
