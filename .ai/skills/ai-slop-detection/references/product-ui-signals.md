# Product UI Review Signals

Heuristics are questions, not universal bans.

- Does every container need to be a card?
- Does each metric help a decision or action?
- Are badges reserved for true state/category semantics?
- Is whitespace helping hierarchy or hiding useful work below the fold?
- Are decorative effects stealing contrast from task controls?
- Does a repeated template rhythm make unrelated content look equally important?
- Is technical language exposed because it helps the user, or because it exists in the backend?
- Is there one clear primary action for the current task?
- Can a returning user orient and act quickly?
