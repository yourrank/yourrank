# Information Architecture & Navigation

1. Inventory user goals and major objects.
2. Inventory current pages/features.
3. Group by user mental model, not code folders.
4. Separate global, workspace, local/contextual navigation and object actions.
5. Remove duplicate destinations.
6. Define consistent labels.
7. Decide when search, filters, breadcrumbs, tabs or sub-navigation are justified.
8. Validate common journeys.

Rules:
- frequent tasks should not be buried,
- advanced/admin areas should not dominate primary users,
- settings are grouped by intent,
- breadcrumbs are for real hierarchy,
- a hamburger menu is not information architecture.

Exit test:
- Where am I?
- What can I do here?
- Where do I go next?
