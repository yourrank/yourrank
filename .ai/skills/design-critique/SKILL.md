# Design Critique

UI review asks: is implementation consistent/correct?
Design critique asks: is this actually a good design for the task?

Critique order:
1. User goal / task success
2. Information architecture
3. Interaction model
4. Hierarchy / density
5. Content clarity
6. Visual system
7. Polish

Challenge:
- unnecessary cards,
- empty space harming scanability,
- decorative metrics,
- equal-priority actions,
- buried primary actions,
- repeated instructions,
- technical jargon,
- bad grouping,
- gratuitous gradients/shadows/glass,
- generic AI SaaS layouts.

For each issue:
```text
severity
evidence
why it hurts
recommended change
```

Do not redesign simply to be different.
