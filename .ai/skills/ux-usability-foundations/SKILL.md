# UX / Usability Foundations

Every interactive element should communicate:
- what it is,
- what it can do,
- what happened after use.

Prefer recognition over recall.
Keep useful context and options visible enough that users do not need to memorize hidden state.

Provide timely feedback for actions and progress for async work.

Use constraints to prevent invalid choices without making input hostile.

Prevent errors using clear scope, defaults, previews, undo and proportional confirmation.

Keep concepts/actions consistent.

Users should understand:
- what changed,
- whether it is saved,
- how to cancel/reverse when feasible.

Primary tasks should not require menu archaeology.
