# Onboarding / First Run

Goal: move users from zero state to first meaningful success.

1. Identify activation event.
2. Identify minimum setup.
3. Default anything safe.
4. Guide required steps in task order.
5. Show progress only when useful.
6. Make skip/later behavior clear where allowed.
7. Connect empty states to meaningful next actions.
8. Remove onboarding chrome when it stops being useful.

Avoid:
- fake metrics pretending the product has data,
- tours users repeatedly dismiss,
- teaching every feature before it is needed,
- permanent checklists after completion.

Returning-user speed must remain excellent.
