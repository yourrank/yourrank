# UX Audit

Map the real flow:
```text
entry → orientation → primary task → feedback → recovery → completion → return use
```

## Audit
- task clarity and primary action
- navigation and wayfinding
- cognitive load and technical jargon
- grouping and terminology
- feedback and recovery
- consistency
- first-run/empty/dense/error/permission states
- responsive and accessibility friction

## Output priority
1. Critical task blockers
2. Major friction/confusion
3. Consistency debt
4. Polish

Do not spend critique budget on radius while users cannot find the action.
