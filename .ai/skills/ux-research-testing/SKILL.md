# UX Research / Usability Testing

Use when product behavior depends on assumptions code cannot prove.

Research plan:
- decision to inform,
- target participant/user type,
- assumptions/questions,
- method,
- success/failure evidence.

Usability tests should use realistic tasks, not leading instructions.

Observe:
- hesitation,
- wrong turns,
- terminology confusion,
- missed actions,
- recovery behavior,
- completion only when meaningful.

Synthesis separates:
- observed evidence,
- participant statements,
- inference,
- recommendation.

Never fabricate research findings.
If users were not tested, label recommendations heuristic rather than user-validated.
