# قائمة تدقيق رحلة الستريمر — YourRank

هذه قائمة تحقق، وليست إعلانًا بأن كل البنود أخطاء موجودة. نطاقها المنتج الحالي: الموقع، المجتمع، الأنشطة الآمنة، الأعضاء، المكافآت المجانية، الإحصاءات، الحساب والفوترة والدعم. لا تشمل تطوير أو إعادة تصميم الأنظمة القديمة المستثناة في AGENTS.md.

## طريقة تسجيل النتائج

- P0: يمنع إجراء أساسيًا، يكشف بيانات، يكرر دفعة أو يسبب فقدان بيانات.
- P1: مسار غير مكتمل أو مضلل، أو خطأ مؤثر يمكن تجاوزه.
- P2: احتكاك أو ضعف وضوح وتنظيم.
- لكل اختبار: الدور والخطة والموقع والجهاز، خطوات التكرار، المتوقع، الفعلي، الدليل، مالك الكود، والإصلاح المقترح.
- النتيجة: PASSED / FAILED / SKIPPED / NOT RUN / NOT VERIFIABLE. لا يُعتبر فحص الكود وحده نجاحًا للسلوك في المتصفح.
- الفحص يبدأ بحساب جديد وموقع فارغ، ثم موقع فيه بيانات، ثم موقع ثانٍ، ثم مشرف بصلاحيات محدودة. تُستخدم بيانات محلية أو تجريبية؛ لا تُنفذ مدفوعات أو عمليات حذف على حساب حقيقي.
